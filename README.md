# にじなな カードリスト（Androidアプリ）

NIJISANJI 7 Colors Card Game の公開済みカードを、スマホで検索・絞り込みして見るための個人用アプリです（非公式）。

- カード／ライバー／商品／用語の4タブ
- 名前・#タグ・効果での検索、商品・種類・属性・カラー・新着での絞り込み
- カード画像は公式Xの投稿画像をその都度読み込んで表示（アプリには同梱しない）
- 一覧を下に引っぱると最新データを再取得

## Expo Go で動かす（Windows パソコン + Android スマホ）

### 1. 準備（最初の1回だけ）
1. パソコンに **Node.js（LTS版）** を入れる：https://nodejs.org/ja
2. スマホに **Expo Go** を入れる：Google Play で「Expo Go」を検索
3. パソコンとスマホを**同じWi-Fi**につなぐ

### 2. アプリを起動
1. この zip をパソコンで展開する
2. 展開したフォルダ（`package.json` がある場所）を開き、アドレスバーに `cmd` と入力して Enter（コマンドプロンプトが開く）
3. 次の2つを順に実行：
   ```
   npm install
   npx expo start
   ```
4. 画面に QR コードが出たら、スマホの **Expo Go** を開き「Scan QR code」で読み取る

初回は読み込みに1分ほどかかります。2回目以降は `npx expo start` だけで起動できます。

### うまくいかないとき
- QR を読んでもつながらない → `npx expo start --tunnel` で起動し直す（初回は追加の部品のインストールを聞かれるので「y」）
- Windows のファイアウォールの確認が出たら「許可」を押す

## データの更新
- `src/data/cards.json` が同梱データです。
- `src/config.ts` の `DATA_URL` に、GitHub に置いた `cards.json` の raw URL を書くと、起動時と引っぱり更新のたびにそこから最新データを読みます（読めないときは前回の保存データか同梱データを表示）。

## 単体アプリ（APK）にしたいとき
Expo の無料アカウントを作り、フォルダで次を実行すると、クラウドで APK が作られてダウンロードリンクが出ます。
```
npx eas-cli@latest login
npx eas-cli@latest build -p android --profile preview
```
（APK 形式の設定は `eas.json` に入っています。初回はプロジェクトの作成を聞かれるので「Yes」。）
